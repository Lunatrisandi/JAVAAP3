# Character Manager — TP3 (Java Visual SIH-6406)

Program konsol Java untuk mengelola karakter game sederhana. Setiap karakter
memiliki nama, tipe (`CharacterType`), level, HP, attack, dan mana, dengan
perhitungan statistik yang dijaga oleh class `Character` melalui encapsulation.
Program juga menampilkan status hidup karakter melalui method `isAlive()`.
